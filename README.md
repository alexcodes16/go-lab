# CS452 Go Lab

This repository contains my work for the Go lab.

## What it includes

- A basic Go program
- Use of an external package with rsc.io/quote
- A custom greetings package
- Error handling
- Unit tests
- Building and installing a Go executable
- Random greeting generation
- A Hellos function for multiple names

## Run

Run the program with:

go run .

## Test

Run the tests with:

go test ./...
